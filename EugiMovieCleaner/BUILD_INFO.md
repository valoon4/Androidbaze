# Windows-EXE Build

Diese Änderung startet den automatischen Windows-Build des Eugi Movie Cleaner.

Das Programm läuft nach dem Download lokal/offline. GitHub Actions benötigt ausschließlich für die Erstellung der ausführbaren Datei eine Verbindung.

Build-Konfiguration: `.github/workflows/build-eugi-movie-cleaner.yml`.
