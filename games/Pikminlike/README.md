# Pikminlike

First game prototype built from the Androidbaze starter.

## Goal

A small squad-based 2D mobile game prototype inspired by creature-command / resource-carrying gameplay.

Initial debug build target:
- one test world
- passive enemies that do not attack the player yet
- player can attack enemies
- collectible / carryable objects
- basic movement and touch controls
- placeholder or prototype art acceptable for the first functional build

## Folder layout

- `src/` – game-specific source/assets when we split the prototype out from the reusable base
- `apks/` – named debug APK snapshots for this game
- `notes/` – design/build notes

## APK naming

Use stable snapshot names such as:

`Pikminlike-debug-v001.apk`

Do not overwrite older snapshots when we want to keep a playable milestone.
