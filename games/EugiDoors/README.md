# Eugi Doors — Retro Prototype 0.2

Android debug prototype in a flat 2D retro JRPG / anime pixel style.

## Included
- Hub room with four doors
- Door 1: side-scrolling endless runner
- Door 2: vertical endless jumper
- Door 3: top-down action-JRPG boss room
- Door 4: true bird's-eye survival arena with a flat segmented worm enemy
- Portrait phone layout
- Pixel HUD, tile-like maps and chibi character/enemy rendering

## Controls
- Hub: tap a door
- Runner: tap / jump control
- Jumper: left/right control
- Boss: D-pad/drag + attack/dodge
- Survival: drag/joystick movement, auto attack
