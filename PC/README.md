# PC-Games

Dieser Ordner ist für unsere PC-Spielprojekte und Prototypen gedacht.

Jedes Spiel bekommt bei Bedarf einen eigenen Unterordner:

```text
PC/<GameName>/
```

Sprache, Engine, Build- und Release-Struktur legen wir pro Spiel fest. PC-Projekte bleiben vom bestehenden Android-/APK-Build im Repo getrennt.
